⚙️ Sincronização via GitHub
Os dados ficam em um arquivo abs_data.json no seu repositório. Leitura é pública — só quem faz upload precisa configurar o token.
  1. No GitHub, vá em Settings → Developer Settings → Personal access tokens → Tokens (classic)
  2. Clique Generate new token, marque apenas a permissão repo (ou public_repo se o repo for público)
  3. Copie o token gerado (começa com ghp_...) — só aparece uma vez
  4. Preencha os campos abaixo com os dados do seu repositório
